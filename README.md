# Hearst-Fujingaho-JP GitHub Organization

このリポジトリには、Organization共通で利用するGitHub Actionsや設定用ファイルを配置します。

組織内リポジトリの分類、命名、分割基準、作成・権限・ブランチ・Pull Request・セキュリティに関するルールの正本は、Privateリポジトリの [.github-private](https://github.com/Hearst-Fujingaho-JP/.github-private) に集約しています。

## このリポジトリで管理するもの

- Organization共通のReusable Workflow
- GitHubが自動的に参照する設定やテンプレート
