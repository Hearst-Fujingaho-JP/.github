# Hearst-Fujingaho-JP GitHub Organization

この文書は、Hearst-Fujingaho-JP Organizationへの参加を検討している方・招待された方に、参加前に確認してほしい基本事項を案内するものです。

## アカウント

- 業務には、原則として会社用の個人GitHubアカウントを使用してください
- 共有アカウントや、個人の既存アカウントの業務利用は避けてください
- 社員が新規に作成する業務用アカウント名には、末尾に `-hdj` を付けてください
- 表示名は、社員は `First Name Last Name(HDJ)`、社外メンバーは `First Name Last Name(会社名)` の形式を推奨します
- メールアドレスは、社員は `hearst.co.jp`、社外メンバーは業務用のものを登録してください
- Bot・CI・自動化用アカウントは、Organization Owner（IT部）の承認を受けてください

## セキュリティ

- Organization参加者は2要素認証（2FA）を有効にしてください
- 機密情報、個人情報、パスワード、APIキー、トークン、秘密鍵、証明書などをGitHubへ登録・commitしないでください
- GitHub Copilotを個人ライセンスで利用する場合は、個人設定の「Allow GitHub to use my data for product improvements」を無効にしてください
- 不正アクセスや情報漏洩の疑いがある場合は、速やかにIT部へ報告してください

## Organizationへの参加

Organizationへの参加には、Organization Owner（IT部）の承認が必要です。招待を受けた後は、担当プロジェクトのTeamに必要最小限の権限で参加します。

参加後に確認するリポジトリの構成・分類・運用ルールは、メンバー向けの [`.github-private`](https://github.com/Hearst-Fujingaho-JP/.github-private) に集約しています。

## 問い合わせ

GitHubに関する問い合わせや参加手続きは、招待時に案内された窓口またはOrganization管理者へ連絡してください。
